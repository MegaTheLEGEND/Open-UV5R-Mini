Pick the features you want, build the firmware in this browser, and flash it over the K1 cable. The compiler runs on this page. Your stock file never leaves your computer.

Before you start

No build is known to be safe to flash. This firmware is in development. It has run on a few radios in debug builds, and that is all.

The cable update mode lives in the app. The radio checks PTT-A + = at power-on inside the app itself. If an app crashes before that check, the radio can't be flashed over the cable again. The way back is then to open the case and use the chip's ROM mode: wires on the G, M and P pads, an ESP32 key sender, and a full flash backup made beforehand (TESTING.md).

Transmit stays inside the amateur bands by default (TX LOCK = HAM). Transmit only where you are licensed.
